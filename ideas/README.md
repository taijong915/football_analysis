# ideas/

어떤 주제로 분석할지 아이디어를 자유롭게 던지고 정리하는 공간입니다. 실제 분석 코드(`notebooks/`, `scripts/`, `src/`)로 옮기기 전 단계의 브레인스토밍/백로그를 여기에 기록합니다.

## 사용 방법

- 새 아이디어는 [`backlog.md`](./backlog.md)의 `대기` 표에 한 줄로 추가합니다. 형식을 갖출 필요 없이 떠오른 대로 적어도 됩니다.
- 아이디어를 구체화했다면(분석 질문, 필요 데이터, 예상 시각화 등) 상태를 `구체화`로 옮기고 세부 내용을 채웁니다.
- 실제로 노트북/스크립트 작업을 시작하면 상태를 `진행중`으로, 결과물이 나오면 `완료`로 옮기고 결과 노트북/이미지 경로를 링크합니다.
- 하지 않기로 한 아이디어는 지우지 말고 `보류`로 옮기며 이유를 한 줄 남깁니다 (나중에 왜 제외했는지 알 수 있도록).

## 상태 값

| 상태 | 의미 |
| :--- | :--- |
| 대기 | 막 떠올린 아이디어, 아직 구체화 전 |
| 구체화 | 분석 질문/필요 데이터/예상 산출물이 정리된 상태 |
| 진행중 | 노트북/스크립트 작업 시작 |
| 완료 | 결과물 존재, 산출물 경로 링크됨 |
| 보류 | 하지 않기로 결정, 이유 기록 |
