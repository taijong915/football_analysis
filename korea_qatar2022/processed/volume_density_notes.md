# 2차원 비교 관찰 메모 (질문 3)

`02_volume_density.py` 실행 결과. 종합 결론은 주제 완료 시 `RESULTS.md`로 옮긴다.

## 두 축

- **양** = 팀이 만든 전진 상황 수 (패스 시작 x 30-80, 세트피스 제외, 조별리그 3경기 합산). 410-1,520건, 중앙값 648건.
- **밀도** = 상황당 침투 선택지. 질문 1~2와 동일하게 **관측 조건 보정(잔차)** 값을 쓴다(5m 기준).
- **색** = 팀이 도달한 최종 라운드 (조별 탈락 / 16강 / 8강 / 4강 / 결승).

## 얽힘 진단 (팀 단위, n=32)

- **전진 상황 수와 오픈플레이 패스 총량('점유 볼륨')은 r=+0.98이다.** 사실상 같은 축이므로, x축을 통제한 잔차 = 점유 볼륨을 통제한 잔차다.
- 밀도(보정 5m) vs 양: r=+0.33 / vs 점유 볼륨: r=+0.40
- 밀도(원시 10m) vs 점유 볼륨: r=+0.54 - PLAN "한계" 절에 적힌 값과 일치.
- **점유 볼륨을 통제하면 진출 상관이 절반 가까이 줄어든다:**

  | 지표 | 진출 상관 | 점유 볼륨 통제 후 |
  | :--- | ---: | ---: |
  | 밀도 원시 10m | +0.33 | +0.19 |
  | 밀도 보정 5m | +0.27 | +0.16 |
  | 밀도 보정 10m | +0.28 | +0.14 |

  즉 "침투 선택지가 많은 팀이 이긴다"의 상당 부분은 "공을 더 가진 팀이 이긴다"로 설명된다. 침투 선택지가 순수한 "침투 의지" 지표가 아니라는 PLAN의 유의사항이 2차원에서 눈으로 확인된다.

## 사분면 (양·밀도 각 중앙값 기준)

| 사분면 | 팀 수 | 진출 | 팀 |
| :--- | ---: | ---: | :--- |
| 양 많음 + 밀도 높음 | 9 | 6 | 아르헨티나, 브라질, 프랑스, 독일, 네덜란드, 스페인, 미국, 캐나다, 에콰도르 |
| 양 많음 + 밀도 낮음 | 7 | 3 | 잉글랜드, 포르투갈, 크로아티아, 벨기에, 덴마크, 카타르, 우루과이 |
| 양 적음 + 밀도 높음 | 7 | 4 | 일본, 세네갈, 스위스, 멕시코, 카메룬, 가나, **한국** |
| 양 적음 + 밀도 낮음 | 9 | 3 | 호주, 폴란드, 모로코, 코스타리카, 이란, 사우디, 세르비아, 튀니지, 웨일스 |

- **결승 진출 팀(아르헨티나·프랑스)과 8강 팀 다수는 "양 많음" 쪽에 있다.** 4강 팀(크로아티아·모로코)은 예외 - 크로아티아는 "양 많음 + 밀도 낮음", 모로코는 "양 적음 + 밀도 낮음"이다. 두 팀은 침투 선택지 밀도가 낮아도 깊이 갔다(수비·역습·세트피스 팀).
- "양 적음 + 밀도 높음"은 일본·세네갈·한국의 자리다. 공은 적게 가졌지만 가진 순간의 침투 준비는 중위권 이상이었다는 뜻.

## 한국

- 전진 상황 수 568건 - 32팀 중 11위(낮은 쪽부터). 공을 오래 쥐고 밀어붙인 팀은 아니다.
- 밀도(보정 5m) -0.002 - 32팀 중앙값(-0.011)과 거의 같다. 질문 1~2의 18위와 일관.
- 점유 볼륨을 통제한 잔차 +0.02 - 0을 살짝 넘는다. **"가진 공 대비 침투 준비"로 보면 한국은 정확히 평균이다.**
- 원시값이 그리던 "전방에 아무도 없었다"는 인상은 (a) 관측 조건(상대가 가장 적게 잡힌 팀)과 (b) 낮은 전진 볼륨의 합작이다. 두 축을 나눠 보면 밀도 자체는 평범하다.

## 유의

- 사분면 경계는 중앙값이라 경계 근처 팀(우루과이·에콰도르 등)은 분류가 불안정하다.
- 라운드는 팀 실력의 대리 지표일 뿐 침투 선택지의 인과 결과가 아니다. 강팀이라 공을 더 갖고, 공을 더 가져서 침투 자리가 생긴다.
- 밀도의 팀 단위 재현성이 낮으므로(질문 1~2, 보정 후 +0.27) y축 위치의 미세한 차이는 논하지 않는다.
