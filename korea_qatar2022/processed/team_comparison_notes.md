# 팀 비교 관찰 메모 (질문 1~2)

`01_team_comparison.py` 실행 결과. 종합 결론은 주제 완료 시 `RESULTS.md`로 옮긴다.

## 대상

- 2022 카타르 월드컵 조별리그 32팀, 오픈플레이 전진 상황(패스 시작 x 30-80, 세트피스 제외) 22,264건
- 팀당 410-1,520건(중앙값 648건)
- 지표: 침투 선택지 5m(`n_launch5`) 기준, 10m(`n_launch`)와 오프사이드 위치(`n_beyond`)를 함께 계산

## 관측 조건 보정

상황 단위로 `n_launch5`를 `n_opp_visible`, `vis_launch`, `max_vis_x`(= `def_line + vis_depth`), `band15`에 회귀한 잔차를 팀 평균으로 삼았다.

- 회귀 설명력은 크지 않다: R^2 = 0.128(5m) / 0.186(10m) / 0.124(오프사이드). 관측 조건이 지표 분산의 13-19%를 설명한다.
- 보이는 상대가 많을수록 침투 선택지가 늘어나는 방향(`n_opp_visible` 계수 +0.070)으로, PLAN의 진단과 부호가 일치한다.
- 필터(`n_opp_visible >= 8`)는 표본을 22,264 -> 13,215건으로 줄이면서도 진출 상관이 +0.31 -> +0.18로 오히려 약해진다. 편향의 기울기를 없애지 못한다는 PLAN의 판단이 재확인됐다. 필터 버전은 CSV에 남겨두되 결론에는 쓰지 않는다.

## 한국

| 지표 | 원시 순위 | 보정 순위 |
| :--- | ---: | ---: |
| 침투 선택지 5m | 3위 | 18위 |
| 침투 선택지 10m | 1위 | 11위 |
| 오프사이드 위치 (구 정의) | 31위 | 8위 |
| 필터(상대 >= 8) 5m | 10위 | - |

(순위는 낮을수록 침투 선택지가 적음. 1위 = 최소)

- 한국은 32팀 중 상대 필드플레이어가 가장 적게 관측된 팀이다: 상황당 평균 5.54명 (32팀 평균 약 7.7명 - 팀별 평균의 평균 7.71, 상황 단위 평균 7.77. 이하 문서는 편의상 7.7로 적는다).
- 원시값에서 한국은 "라인 앞에 준비된 선수가 거의 없고(하위 3위) 라인을 넘어간 선수는 많은(상위 2위)" 극단적인 팀으로 보인다. 보정하면 둘 다 중위권(18위 / 8위)으로 이동한다.
- 필터 버전(10위)과 보정 버전(18위)이 방향은 같지만 크기가 다르다. 필터는 저관측 상황을 버릴 뿐 남은 상황의 라인 추정 편향은 그대로라, 한국처럼 전 구간이 저관측인 팀에는 보정만큼 밀어 올리지 못한다.

## 해석 시 유의 (PLAN "한계" 재확인)

- 침투 선택지는 상대 수비 라인 깊이(r=+0.82), 점유 볼륨(r=+0.54)과 얽혀 있어 "침투 의지"만 잰 값이 아니다. 질문 3의 2차원 표현에서 이 얽힘을 드러낸다.
- 3경기 팀 평균 신뢰도가 낮다(보정 후 재현성 +0.27). 개별 팀의 "몇 위"가 아니라 분포에서의 대략적 위치로만 서술한다.
- 회귀 보정은 관측 조건과 지표의 관계가 선형이라고 가정한다. 잔차 자체가 팀 스타일 + 남은 관측 잡음의 혼합이다.
