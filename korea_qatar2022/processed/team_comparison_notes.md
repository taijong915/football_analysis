# 팀 비교 관찰 메모 (질문 1~2)

`01_team_comparison.py`가 실행 때마다 새로 쓰는 파일이다. 손으로 고치지 말 것 - 종합 결론은 `RESULTS.md`에 있다.

## 대상

- 2022 카타르 월드컵 조별리그 32팀, 오픈플레이 전진 상황(패스 시작 x 30-110, 세트피스 제외) 29,690건
- 팀당 536-1,990건(중앙값 840건)
- 지표: 채널 침투 선택지 5m(`n_channel5`) 기준. 중앙 5m(`n_center5`)를 대조군으로, 채널 10m(`n_channel10`)와 오프사이드 위치(`n_beyond`)를 함께 계산

## 관측 조건 보정

상황 단위로 지표를 `n_opp_visible`, `max_vis_x`, `band15`, `vis_launch_wide`, `vis_launch_half`, `vis_launch_center`에 회귀한 잔차를 팀 평균으로 삼았다. 전 폭 가시율 대신 레인별 가시율을 쓰는 이유는 채널이 세는 사이드가 세 레인 중 가장 안 보이기 때문이다(`PLAN.md`의 재적합 결과 절).

- 회귀 설명력은 크지 않다: R^2 = 0.056(n_channel5) / 0.083(n_channel10) / 0.161(n_center5) / 0.084(n_beyond).
- 필터(`n_opp_visible >= 8`)는 표본을 29,690 -> 19,310건으로 줄이면서도 진출 상관이 +0.36 -> +0.28로 약해진다. 편향의 기울기를 없애지 못하므로 결론에는 쓰지 않는다.

## 핵심 수치

| | 보정 전 | 보정 후 |
| :--- | ---: | ---: |
| 보정 전/후 팀 순위 상관 (Spearman) | | +0.88 |
| 5계단 이상 이동한 팀 | | 10 / 32 |
| 경기 간 재현성 (경기쌍 평균 상관) | +0.45 | +0.36 |
| 16강 진출 상관 (채널 5m) | +0.36 | +0.34 |
| 16강 진출 상관 (채널 10m) | +0.36 | +0.35 |
| 16강 진출 상관 (중앙 5m, 대조군) | +0.12 | -0.13 |
| 오프사이드 위치 vs 진출 상관 | -0.40 | -0.22 |

- 보정 후 상위 5: 스페인, 브라질, 세네갈, 아르헨티나, 캐나다
- 보정 후 하위 5: 이란, 모로코, 코스타리카, 웨일스, 포르투갈
- **중앙 대조군은 보정하면 진출과의 관계가 뒤집힌다.** 채널은 양의 상관을 유지하는데 중앙은 음으로 돌아선다 - 컷백을 받으러 중앙에 서 있는 인원이 많은 것은 좋은 신호가 아니다.

## 한국

| 지표 | 원시 순위 | 보정 순위 |
| :--- | ---: | ---: |
| 채널 침투 선택지 5m | 8위 | 15위 |
| 채널 침투 선택지 10m | 2위 | 13위 |
| 중앙 5m (대조군) | 10위 | 25위 |
| 오프사이드 위치 (최초 정의) | 29위 | 14위 |
| 필터(상대 >= 8) 채널 5m | 8위 | - |

(순위는 낮을수록 지표가 작음. 1위 = 최소)

- 한국은 32팀 중 상대 필드플레이어가 가장 적게 관측된 팀이다: 상황당 평균 6.18명(32팀 평균 7.98명, 상황 단위).
- 사이드 레인 가시율도 0.612로 32팀 중 최저다(32팀 평균 0.690). 채널 지표가 세는 구역이라 보정 폭이 큰 팀에 속한다.

## 해석 시 유의 (PLAN "한계" 재확인)

- 채널 침투 선택지는 상대 수비 라인 깊이·점유 볼륨과 얽혀 있어 "침투 의지"만 잰 값이 아니다. 질문 3의 2차원 표현에서 이 얽힘을 드러낸다.
- 3경기 팀 평균의 재현성이 높지 않다(보정 후 +0.36). 개별 팀의 "몇 위"가 아니라 분포에서의 대략적 위치로만 서술한다.
- 회귀 보정은 관측 조건과 지표의 관계가 선형이라고 가정한다. 잔차 자체가 팀 스타일 + 남은 관측 잡음의 혼합이다.
