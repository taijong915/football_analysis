# 한국 대조 관찰 메모 (질문 4)

`03_korea_contrast.py` 실행 결과. 종합 결론은 주제 완료 시 `RESULTS.md`로 옮긴다.

## 질문

원시값에서 한국은 두 방향으로 극단이다:
- **침투 선택지**(라인 앞 5m에서 온사이드로 준비된 선수): 32팀 중 하위 3위
- **오프사이드 위치**(라인을 넘어간 선수, 구 정의): 32팀 중 상위 2위 (낮은 쪽부터 31위)

이 극단이 실제 경기 내용인가, 아니면 한국 경기의 중계 화면 구성(관측 조건)의 산물인가?

## 근거 1 - 한국은 32팀 중 상대가 가장 적게 잡힌 팀

- 상황당 관측된 상대 필드플레이어: 한국 **5.54명**, 32팀 평균 약 7.7명, 32팀 중 최저.
- 두 번째로 적은 에콰도르(6.42명)와도 0.88명 차 - 한국이 뚜렷한 외톨이 값이다.
- 경기별로도 세 경기 모두 평균 아래: vs 포르투갈 6.06 / vs 우루과이 5.73 / vs 가나 5.09. 극단은 한 경기 탓이 아니다.

## 근거 2 - 관측 조건이 지표를 미는 방향이 한국의 원시 패턴과 일치

상황 단위 상관 (`n_opp_visible` vs 지표):

| | 침투 선택지 | 오프사이드 위치 |
| :--- | ---: | ---: |
| 전체 상황 | +0.30 | -0.23 |
| 한국 상황만 | +0.17 | -0.27 |

상대가 적게 보일수록 추정 오프사이드 라인이 얕아져서 (a) 라인 앞에 잡히는 준비 선수가 줄고 (b) "라인을 넘었다"고 잘못 분류되는 선수가 는다. **한국의 원시 패턴(침투 선택지 최소 + 오프사이드 위치 최다)이 정확히 이 방향이다.**

## 근거 3 - 관측 조건을 겨냥한 처리에서만 극단이 풀린다

한국 순위 (1 = 지표 최소, 32 = 최대):

| 처리 | 침투 선택지 | 오프사이드 위치 |
| :--- | ---: | ---: |
| 원시 | 3위 | 31위 |
| `vis_launch` >= 0.85 필터 | 1위 | 32위 |
| `n_opp_visible` >= 8 필터 | 10위 | 25위 |
| 회귀 보정 (관측 조건 공변량) | 18위 | 8위 |

- **`vis_launch` 필터는 오히려 한국을 더 극단으로 민다.** 출발 구역 가시율은 *추정된* 라인 주변만 보므로, 라인 자체가 얕게 잘못 잡힌 상황을 걸러내지 못한다 (PLAN "한계" 절, 프리즈프레임으로 확인된 사례와 일치).
- **상대 관측 수를 직접 겨냥한 필터**는 침투 선택지를 3위 -> 10위로 끌어올린다.
- **회귀 보정**은 두 지표를 모두 중위권으로 옮긴다: 침투 선택지 18위(값 -0.002, 32팀 중앙값 -0.011과 사실상 동일), 오프사이드 위치 8위(값 -0.044, 중앙값 -0.023보다 낮음 - 원시값의 "상위 2위"가 "평균보다 약간 적은 쪽"으로 반전).

## 결론

한국의 침투 선택지 극단은 **실제 경기 내용보다 중계 화면 구성에 가깝다.** 세 근거가 같은 방향을 가리킨다: (1) 한국은 관측 조건 자체가 32팀 중 가장 나쁘고, (2) 그 조건이 지표를 미는 방향이 한국의 원시 패턴과 일치하며, (3) 조건을 겨냥한 보정을 하면 두 극단이 모두 중위권으로 이동한다.

**보정 후에도 남는 차이:** 침투 선택지는 사실상 없다(정확히 중앙값). 오프사이드 위치는 방향이 반대로 뒤집혀 평균보다 약간 적은 쪽이다. 즉 "한국은 전방에 준비된 선수가 유독 없었다"는 원시값의 인상은 데이터로 뒷받침되지 않는다. 질문 3의 결론과 종합하면, 한국은 **가진 공은 적었지만(전진 볼륨 11위) 가진 순간의 침투 준비는 평범했다.**

## 유의

- 회귀 보정은 관측 조건과 지표의 관계가 선형이라 가정한다. 한국의 `n_opp_visible`(5.54)은 회귀 표본 대부분(6-9명)보다 바깥이라 보정값이 선형 외삽에 의존한다 - 보정 순위의 정확한 등수(18위)보다 "극단에서 중위권으로"라는 방향에 무게를 둔다.
- 필터와 회귀가 오프사이드 위치에서 서로 다른 등수를 준다(25위 vs 8위). 공통점은 "원시값의 상위 2위는 견고하지 않다"는 것.
